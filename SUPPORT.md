# Getting Help

- **Questions and general help:** use [Discussions](https://github.com/ChoutesOS/choutesos/discussions).
- **Bug reports:** open an issue with the [bug report form](https://github.com/ChoutesOS/choutesos/issues/new/choose).
- **Feature requests:** open an issue with the [feature request form](https://github.com/ChoutesOS/choutesos/issues/new/choose).
- **Security vulnerabilities:** report them privately as described in the [security policy](https://github.com/ChoutesOS/.github/blob/main/SECURITY.md).

Before opening a new issue, please search existing issues and discussions to see whether your question has already been answered.
