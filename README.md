# ChoutesOS

ChoutesOS is an Arch-based Linux distribution with a custom KDE Plasma desktop, built for gaming and everyday use. This repository is the official hub for users: report bugs, suggest features, and join the discussion.

## Status

ChoutesOS is under active development. No stable release has been published yet, so there is no supported ISO to install at this time. Download and installation instructions will be added here when the first release is available.

## Project goals

- **A distinct KDE Plasma desktop.** A ChoutesOS look and feel with its own theme, icons, cursors, wallpapers, and panel layout, rather than stock Plasma.
- **Graphical installation.** Installation with Calamares on UEFI and BIOS systems, and in virtual machines.
- **Gaming and daily use on AMD and Intel graphics.** Mesa, Vulkan, Steam, Wine, GameMode, MangoHud, Gamescope, and Proton tooling.
- **Open-source graphics drivers only.** Proprietary NVIDIA drivers are not provided; the open-source nouveau driver is used instead.
- **Rolling updates.** Updates delivered through a signed pacman repository, so existing installations stay current with a regular system update.
- **Beginner-friendly defaults.** An app store with Flathub ready to use, sound, Bluetooth, printing, codecs, fonts, firewall, and system snapshots configured out of the box.

## Getting help

- **Questions:** ask in [Discussions](https://github.com/ChoutesOS/choutesos/discussions).
- **Bugs:** open an issue with the [bug report form](https://github.com/ChoutesOS/choutesos/issues/new/choose).
- **Feature requests:** open an issue with the [feature request form](https://github.com/ChoutesOS/choutesos/issues/new/choose).
- **Security vulnerabilities:** report them privately, as described in the [security policy](https://github.com/ChoutesOS/choutesos/blob/main/SECURITY.md).
