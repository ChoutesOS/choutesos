# Security Policy

## Supported versions

ChoutesOS has not published a stable release yet. Security fixes are applied to the current development state of each repository and will be delivered to users through the ChoutesOS package repository once it is available.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions, or pull requests.

Report them privately using GitHub's confidential reporting form:

<https://github.com/ChoutesOS/choutesos/security/advisories/new>

Please include:

- A description of the vulnerability and its potential impact
- The affected component and version
- Steps to reproduce, or a proof of concept
- Any suggested fix or mitigation

We will acknowledge your report as soon as we can, keep you informed about progress, and credit you when the fix is published, unless you prefer to remain anonymous.

## Scope

This policy covers ChoutesOS-specific code, configuration, packaging, and infrastructure in the repositories of the [ChoutesOS GitHub account](https://github.com/ChoutesOS).

Vulnerabilities in upstream software, such as Arch Linux packages, the Linux kernel, KDE Plasma, or Calamares, should be reported to the respective upstream projects. If a ChoutesOS configuration makes an upstream issue easier to exploit, please report that to us as well.
